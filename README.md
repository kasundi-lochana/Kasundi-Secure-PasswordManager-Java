# Secure Password Manager

A console-based password manager built in Java to practice 
ArrayList usage and Base64 cryptographic encoding.

## Features
- Store and manage passwords in a simple console interface
- Uses ArrayList for in-memory data storage
- Base64 encoding for basic password protection

## What I Learned
- Object-Oriented Programming (OOP) concepts in Java
- Working with ArrayList collections
- Basics of cryptographic encoding

## Tech Stack
- Java
